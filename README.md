# Jahan Traders - Official Website

Welcome to the official repository of **M/S Jahan Traders**, a leading Jute & Jute Products Exporter and Manufacturer in Bangladesh (established in 1974).

## 🛠️ Tech Stack
* **HTML5**
* **Tailwind CSS** (Styling)
* **Alpine.js** (Interactive UI & Dropdowns)
* **FontAwesome** (Icons)

## 🚀 Features
* Responsive corporate navigation with interactive dropdowns.
* Smooth scroll animations for sections.
* Product showcases (Jute Sacks, Yarn, Geotextiles, Handicrafts).
* Interactive Contact Form and Google Map integration.
