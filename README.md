# M/S Jahan Traders - Official Website

Welcome to the official repository of **M/S Jahan Traders**, a leading Jute & Jute Products Exporter and Manufacturer. This repository contains the complete frontend codebase for the company's corporate profile and e-commerce inquiry platform.

## 📁 Project Structure

* `index.html` - Homepage showcasing the brand overview and highlights.
* `about.html` - Company history, mission, and background details.
* `products.html` - Comprehensive showcase of jute products with interactive modals.
* `contact.html` - Contact form, corporate address, and map integration.
* `style.css` - Custom styling, animations, and custom cursor configurations.
* `script.js` - Global scroll animations (Intersection Observer), modals, and interactive UI logic.
* `logo.png` - Official brand logo.

## 🛠️ Tech Stack

* **HTML5** (Structure)
* **Tailwind CSS** (Styling & Responsive Design)
* **Alpine.js** (Interactive UI & Dropdowns)
* **Vanilla JavaScript** (Animations & Custom Cursor)
* **FontAwesome** (Icons)

## 🚀 Features

* Fully responsive modern corporate design.
* Interactive product inquiry modal system.
* Smooth scroll-triggered animations.
* Custom animated cursor and hover effects.
* Multi-page corporate architecture (`Home`, `About`, `Products`, `Contact`).
